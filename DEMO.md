# Защита «Развилка» за 5 минут
Запустите start.bat. Используйте «Локальный помощник», чтобы показ не зависел от сети. Честно скажите: есть интеграция OpenAI и разрешённый кейсом локальный резервный режим.

## 0:00–0:35 · Проблема
«Бизнес пишет “Хотим AI для анализа отзывов”. Одна команда понимает это как отчёт, другая — как ответы клиентам, третья — как срочные сигналы. Мы делаем эти расхождения видимыми до начала разработки».

Конструктор → введите **Хотим AI для анализа отзывов** → выберите **Срочные сигналы** → **Разобрать задачу**.

## 0:35–1:45 · Уточнение и рост готовности
Покажите 3–5 ситуационных вопросов. Ответьте на них, затем дополните остальные поля редактора. Можно использовать следующие синтетические ответы:

| Поле | Ответ |
|---|---|
| Название | Отзывы: заметить проблему вовремя |
| Контекст | Учебная сеть кофеен получает отзывы в нескольких каналах. |
| Потребность | Управляющий должен вовремя замечать негатив и связываться с гостем. |
| Данные | 300 синтетических отзывов в CSV; файл передаёт бизнес на старте. |
| Пользователи | Управляющий проверяет сигнал и решает, кому поручить ответ. |
| Ожидаемый результат | Прототип срочных уведомлений о негативных отзывах и дашборд тем. |
| Критерии | На 30 размеченных примерах найти 24 негативных; уведомление за 60 секунд. |
| Ограничения | 2 недели, только синтетические данные, ручная проверка ответов. |
| Контакт | manager@coffee.example |
| Обратная связь | Созвон каждый вторник; проверка результата в течение 24 часов. |

Чтобы показать механику, сначала подтвердите только контекст (+10) и результат (+15): 25/100 Draft. Затем **Проверил — подтвердить заполненные поля**: 100/100 Priority. Измените одно поле: его баллы снимаются; подтвердите снова. Покажите разбор по категориям и маршрут.

Отдельно подтвердите публикацию → **Опубликовать в каталоге**.

## 1:45–2:40 · Отклик
Каталог → новая задача находится сверху → **Предложить решение**.
Активная команда Campus Coders.

- Идея: «NLP-классификатор негативных отзывов и уведомления управляющему».
- План: «Разметка → прототип → уведомления → проверка 30 примеров».
- Срок: «2 недели».
- Мы считаем задачу выполненной, когда: «Найдены 24 негативных отзыва из 30; уведомления приходят за 60 секунд».
- Отправить предложение.

## 2:40–3:40 · Бизнес выбирает
Кабинет бизнеса → выберите свою новую задачу → сравните ожидание и понимание команды → **Выбрать команду**.

Для наглядного расхождения откройте готовую задачу **Отзывы, которые не останутся без ответа**. Там два синтетических предложения: Campus Coders предлагает уведомления, Data Sprouts — еженедельный отчёт. Система подсвечивает расхождение, но не принимает решение.

Можно принять оба предложения или отклонить оба. Выбор одного не меняет второе.

## 3:40–4:35 · Результат и XP
Вернитесь к своей задаче → этап «Работающий прототип» → доказательство «Проверены тестовые примеры» → **Подтвердить этап**: +10 XP.
Моя команда → своё принятое предложение → описание «Прототип готов; все критерии пройдены» → **Сдать результат**.
Кабинет бизнеса → 5 ★ → «Согласованные тесты пройдены» → подтвердите связь с критериями → итоговый отзыв: +40 XP.
Лидеры → у команды 50 XP и одна оценённая задача.

## 4:35–5:00 · Завершение
«Главная мотивация бизнеса — качество постановки: ясная и подтверждённая задача получает высокий рейтинг. Студенты свободно выбирают задачи, бизнес сам выбирает команды. AI помогает уточнять, а решение и подтверждение всегда остаются у человека».

Страница «О проекте» показывает промпт, вход/выход, правила рейтинга и ограничения MVP.
