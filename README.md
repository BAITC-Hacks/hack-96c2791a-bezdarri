# TaskForge — AI Task Gamification Platform

Ссылка:
TaskForge — Streamlit MVP для хакатона AI Sana. Он помогает бизнесу превратить короткое описание проблемы в понятную карточку задачи, оценить её готовность, опубликовать в каталоге и вручную выбрать студенческие команды по их предложениям.

## Что уже работает

1. Бизнес создаёт задачу вручную или нажимает **Analyze with AI**.
2. AI оценивает заполненность, предлагает 3–5 уточняющих вопросов и формирует редактируемую карточку.
3. Бизнес проверяет факты, подтверждает карточку и публикует задачу.
4. Команды видят общий каталог, фильтруют задачи и отправляют предложение: идею, план, срок и ссылку на прототип.
5. Бизнес в панели управления вручную принимает или отклоняет каждое предложение. Для одной задачи можно принять несколько команд.

AI не назначает исполнителя и не публикует задачу сам. Решение всегда принимает представитель бизнеса.

## Концепция «Развилка»

Одна короткая задача может означать разные продукты. Например, «Хотим AI для анализа отзывов» может привести к дашборду для руководителя, автоматическим ответам клиентам или уведомлениям о срочных жалобах.

В дальнейшем TaskForge будет показывать такие варианты как гипотезы и просить бизнес выбрать нужный результат до публикации. Это уменьшает риск того, что команда и заказчик понимают успех по-разному. В предложении команды смогут явно указывать: **«Мы считаем задачу выполненной, когда…»**.

## Запуск

Нужен Python 3.10 или новее. В PowerShell из папки проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m streamlit run app.py
```

В `.env` добавьте свой ключ в переменную `OPENAI_API_KEY`. По умолчанию используется `gpt-4o-mini`; модель можно сменить через `OPENAI_MODEL`.

Откройте `http://localhost:8501`. Без ключа по-прежнему доступны ручное создание задач, каталог, предложения и решения бизнеса; AI-функции покажут ошибку конфигурации.

## Основной сценарий

**Описание задачи → AI-анализ → уточняющие вопросы → редактируемая карточка → Readiness Score → публикация → каталог → предложение команды → ручное решение бизнеса**

Для демо используйте слабое описание, например: «Хотим AI для анализа отзывов». Покажите вопросы, заполните карточку, подтвердите её, опубликуйте задачу, отправьте предложение от команды и примите либо отклоните его в Business Dashboard.

## Readiness Score

Рейтинг показывает готовность конкретной задачи к работе со студентами. Для задач, созданных с AI, оценка формируется моделью по рубрике и сохраняется вместе с карточкой. Для исходных демонстрационных задач используется прозрачный чек-лист заполненности.

| Критерий | Максимум |
|---|---:|
| Контекст и потребность бизнеса | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт и формат взаимодействия | 10 |
| **Итого** | **100** |

| Балл | Уровень |
|---:|---|
| 0–39 | Draft |
| 40–69 | Working |
| 70–89 | Ready |
| 90–100 | Priority |

Каталог сортируется по рейтингу, а низкий балл не скрывает задачу и не запрещает командам откликнуться. В карточке отображаются разбивка баллов, недостающие поля и рекомендации по улучшению.

## AI и проверка фактов

AI получает только описание задачи, текущую карточку и ответы пользователя после нажатия кнопки AI. Результат содержит вопросы, поля с недостающей информацией и оценку по рубрике. AI не должен добавлять факты, которых не было во входных данных: неизвестные поля остаются пустыми.

Перед публикацией бизнес обязан просмотреть карточку и подтвердить её. Невалидный ответ AI, отказ модели или ошибка API не заменяют текущий черновик. Запросы к API выполняются с `store=False`; ключ не сохраняется в данных задач и не показывается в интерфейсе.

## Каталог и предложения

В каталоге доступны фильтры по уровню готовности и сортировка по рейтингу. Каждое предложение содержит:

- название команды;
- идею решения;
- план реализации;
- предполагаемый срок;
- необязательную ссылку на прототип.

Бизнес видит предложения в **Business Dashboard** и вручную меняет их статус на `Accepted` или `Rejected`. Автоматический выбор команды запрещён.

## Командный рейтинг: следующее расширение

Следующим этапом можно добавить профиль команд, отзывы бизнеса и XP. После принятия результата бизнес ставит оценку от 1 до 5 и оставляет комментарий; высокая оценка добавляет XP, низкая уменьшает его. В таблице лидеров стоит показывать общий XP, среднюю оценку и число завершённых задач, чтобы бизнес видел опыт команды, но по-прежнему выбирал её сам.

## Структура проекта

```text
app.py                 # интерфейс Streamlit: создание, каталог, панель бизнеса
requirements.txt       # зависимости Python
.env.example           # шаблон настроек OpenAI
data/
  tasks.json           # опубликованные задачи
  teams.json           # демонстрационные команды
  proposals.json       # предложения и их статусы
services/
  ai.py                # Structured Outputs, проверка ответа и ограничение фактов
  scoring.py           # формула рейтинга и уровни готовности
  storage.py           # безопасная работа с JSON
tests/                 # проверки сценариев MVP и AI-валидации
```

Данные хранятся локально в JSON и предназначены для одного пользователя в демо-режиме. Не добавляйте реальные персональные или коммерчески чувствительные данные.

## Проверка

Запустите тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют временные JSON-файлы и мокают обращения к OpenAI, поэтому ключ и расходы API для них не нужны.
