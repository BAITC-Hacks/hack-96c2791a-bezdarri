# Развилка · TaskForge — AI Sana
Готовый MVP для кейса «Рейтинг качества бизнес-задач и открытый выбор команд».

**Идея → возможные интерпретации → 3–5 вопросов → редактируемая карточка → подтверждение → рейтинг → каталог → предложение → сравнение ожиданий → выбор бизнеса → этапы → сдача → отзыв / XP.**

## Быстрый запуск
Python 3.10+. На Windows дважды нажмите **start.bat**. Первый запуск создаёт .venv и устанавливает зависимости. Интернет нужен для первой установки; локальный помощник затем работает без API.

Или из каталога проекта:
~~~powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
~~~
Откройте http://localhost:8501. На Linux/macOS используйте python3 и .venv/bin/python.

## Что реализовано
- «Развилка»: три возможных результата под тему описания, выбор нескольких или своего варианта. Варианты явно обозначены как гипотезы.
- Содержательная интеграция OpenAI: анализ описания и ответов, структурирование фактов, 3–5 ситуативных вопросов. Явный локальный резервный режим с правилами.
- Карточка: название, контекст, потребность, пользователи, данные, ограничения, результат, критерии, контакт, формат обратной связи.
- Подтверждение каждого поля, пакетное подтверждение проверенных полей и отдельное подтверждение публикации.
- Живой Readiness Score, разбор, рекомендации с баллами, уровни, «До → После», маршрут данных и действий, достижения.
- Повторное редактирование опубликованной задачи с пересчётом рейтинга и повторным подтверждением.
- Каталог без порога входа: поиск, тема, уровень, диапазон баллов, сортировка по рейтингу/дате/навыкам. Экспорт карточки в Markdown.
- Профили команд: интересы, навыки, технологии. Skill Match = доля совпавших требуемых навыков, с объяснением каждого совпадения; при отсутствии требований процент не выдумывается.
- Неограниченные предложения: идея, план, срок, необязательная HTTP(S)-ссылка и «Мы считаем задачу выполненной, когда…».
- Таблица сравнения; ожидания бизнеса и команды рядом; подсказка о потенциальном расхождении по ключевым словам.
- Ручной выбор одной, нескольких или ни одной команды. Принятие предложения не меняет остальные.
- Независимые этапы и сдача результата каждой командой, отзывы, XP, лидерборд, достижения команды.
- Валидация в сервисах, атомарное сохранение JSON, блокировка параллельных изменений внутри одного серверного процесса.
- Пять синтетических черновиков, пять карточек разных уровней, пять заполненных профилей, пять предложений. Ранее созданные пользователем задачи сохранены.

## Рейтинг
Одинаковый детерминированный алгоритм для ручных и AI-карточек. AI не начисляет баллы.

| Категория | Баллы |
|---|---:|
| Контекст и потребность | 20 (10 + 10) |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 (контакт 5 + формат/обратная связь 5) |

Поле даёт баллы, когда оно заполнено и подтверждено человеком. Пустое, «пока не знаю», «Not provided», «no data» и другие явные заглушки дают 0. Редактирование снимает подтверждение поля и публикации. Полнота не доказывает содержательное качество: бизнес подтверждает факты и измеримость приёмки самостоятельно.

**Draft 0–39 · Workable 40–69 · Ready 70–89 · Priority 90–100.**

Сортировка каталога по умолчанию — рейтинг по убыванию, затем новизна. Даже 0-балльную задачу можно подтвердить, опубликовать и получить отклик. Нет скрытого отсечения по уровню или навыкам. Legacy-записи без сведений о подтверждении получают 0 до повторного подтверждения, а не фиктивное доверие.

## Этапы, отзывы и XP
Этап подтверждает бизнес, указав результат и доказательство проверки: **+10 XP**, максимум **два этапа на команду по задаче**, даже при нескольких предложениях той же команды.

Команда сдаёт результат на странице «Моя команда». После этого бизнес оставляет один итоговый отзыв на команду по задаче.

| Оценка | XP |
|---|---:|
| 1 ★ | −20 |
| 2 ★ | −10 |
| 3 ★ | 0 |
| 4 ★ | +20 |
| 5 ★ | +40 |

Отзыв обязателен; для низкой оценки нужно описать причину относительно согласованных критериев и подтвердить это в форме. Программа не может проверить истинность обоснования — ответственность у бизнеса.

XP вычисляется по хронологическому журналу подтверждённых этапов и отзывов, с нижней границей 0 после каждого события. Начисления за этапы остаются в журнале, отзыв — отдельная операция. Повторные отзывы, повторный этап и третий этап отклоняются сервисом. После начала работы решение нельзя переписать задним числом. Критерии фиксируются при выборе команды: последующая правка задачи не меняет её согласованную приёмку.

Профиль показывает XP, среднюю оценку, число завершённых и оценённых задач, отзывы. Лидерборд сортируется по XP, затем числу оценённых задач; рейтинг не назначает исполнителей.

## AI: подключение и честный резервный режим
Скопируйте .env.example в .env **только если .env ещё нет**, вставьте свой OPENAI_API_KEY, при необходимости измените OPENAI_MODEL. Ключ не вводится в интерфейс и не попадает в архив, JSON или сообщения ошибок.

Выберите «OpenAI» перед нажатием «Разобрать задачу». Используется Responses API, strict JSON Schema, store=False, таймаут 35 секунд, без автоматических повторов. В API уходят введённое описание, выбранная интерпретация, текущие поля и ответы. Вызов происходит только по действию пользователя; каталог, рейтинг и решения не вызывают AI.

Промпт и схема: services/ai.py и страница «О проекте». Пример входа:
~~~json
{"mode":"draft","description":"Хотим AI для анализа отзывов","confirmed_interpretation":"","current_card":{},"answers":[]}
~~~
Выход: task со всеми строковыми полями карточки и questions из 3–5 объектов field/question. Неизвестные поля пустые. Все результаты AI маркированы «AI Generated — Review Required».

Проверяются структура, типы, полнота схемы, число/уникальность вопросов, отсутствие новых чисел, email и URL вне пользовательских источников. Это частичная проверка происхождения фактов, не доказательство семантической истинности. Ошибка API, отказ, неверный JSON или неподтверждённые сведения сохраняют текущий черновик и показывают безопасное сообщение. Переключитесь на локальный режим для продолжения.

**Локальный помощник** — явно обозначенная заглушка: переносит исходное описание в контекст дословно, учитывает выбранный результат и ответы, задаёт вопросы по отсутствующим полям. Не имитирует подключение к модели. Он достаточен для автономной демонстрации согласно кейсу.

«Развилка», Skill Match и проверка ожиданий реализованы правилами. Проверка ожиданий находит только ключевые сигналы, например «уведомления» против «еженедельного отчёта»; не является семантической AI-экспертизой и не выбирает победителя.

## Структура
~~~text
app.py                 # Шесть страниц Streamlit, состояния редактора и формы
services/
  ai.py                # OpenAI, контракт, валидация, локальный режим
  scoring.py           # Подтверждённые поля и единая шкала
  storage.py           # JSON, бизнес-правила, этапы/сдача/отзывы, XP
  matching.py          # Интерпретации, навыки, ожидания, экспорт
data/                  # tasks, teams, proposals, drafts
tests/                 # Domain, API contract и сквозные UI-тесты
DEMO.md                # Сценарий защиты до 5 минут
start.bat              # Запуск на Windows
~~~

## Проверка
~~~powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
~~~
Тесты используют временные копии данных и HTTP-заглушку через настоящий OpenAI SDK. Они проверяют весь UI-путь до отзыва, подтверждение и снятие баллов после правки, публичность Draft, сортировку, множественный выбор, ограничения XP, сохранение критериев, плохой JSON, небезопасные ссылки и конкурентные отклики. API-ключ не требуется, платных вызовов нет.

## Ограничения MVP
- Демо без регистрации и проверки владельца: все посетители могут переключать роли/команды и пользоваться кабинетом бизнеса. Это соответствует объёму хакатона, но не production.
- Один процесс Streamlit и локальные JSON. Для публичного многосерверного запуска нужны аутентификация, права, база данных и транзакции.
- Черновик сохраняется в текущей сессии при навигации; опубликованные задачи и вся работа команд сохраняются на диске. Обновление браузера начинает новую сессию.
- Все seed-контакты и ссылки example.com/.example демонстрационные. Наборы отзывов или внешние прототипы не прилагаются.
- Реальный ответ OpenAI зависит от модели и сети. Офлайн-контракт проверен; живой запрос требует вашего ключа.
- Скрипт seed_demo.py обновляет только именованные демонстрационные карточки и профили; **не запускайте его после подготовки своей демонстрации**, если изменяли эти seed-карточки. Обычный запуск приложения ничего не сбрасывает.
